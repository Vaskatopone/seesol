# See & Sol

Бутик брендовой оптики в Минске: адаптивная витрина и каталог с админ-панелью.

## Запуск для разработки

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Укажите свой ADMIN_PASSWORD в .env
uvicorn main:app --reload --port 8080
```

В другом терминале:

```bash
npm install
npm run dev
```

Откройте адрес Vite из вывода команды. API работает на порту `8080`.

## Каталог и администрирование

Каталог хранится в SQLite в файле `seesol.db` (путь можно поменять через `DATABASE_PATH`). При первом запуске база заполняется несколькими стартовыми моделями; они редактируются и удаляются как обычные карточки. Вход администратора — кнопка с иконкой замка в шапке. Пароль задаётся только переменной окружения `ADMIN_PASSWORD`; администратор может создавать, редактировать и удалять модели, а покупателям изменения видны сразу.

В карточке модели можно указать бренд, название, категорию, описание, цену и HTTPS-ссылку на фотографию. Пустая цена отображается как «Уточняйте в бутике». У стартовых моделей цену и фото можно заменить на актуальные через админ-панель.

## Сборка и запуск

```bash
npm run build
ADMIN_PASSWORD='ваш-длинный-уникальный-пароль' uvicorn main:app --host 0.0.0.0 --port 8080
```

После сборки FastAPI раздаёт `dist` и API с одного origin. Для публичного размещения используйте HTTPS и задайте надёжный `ADMIN_PASSWORD`; SQLite-файл должен находиться на постоянном диске.

## Просмотр на GitHub Pages

Workflow автоматически собирает статическую витрину и публикует её при каждом push в `main`. После успешного запуска GitHub Actions сайт будет доступен по адресу https://vaskatopone.github.io/seesol/. Workflow также можно запустить вручную во вкладке **Actions**. Для репозитория должен быть разрешён источник GitHub Pages **GitHub Actions** (Settings → Pages → Build and deployment → Source).

Pages показывает витрину и стартовые карточки в демонстрационном режиме. Управление каталогом требует запущенного FastAPI backend, поэтому на статическом preview админ-панель отключена.
